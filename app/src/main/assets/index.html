Testar um sensor

Escolha o sensor, informe a temperatura dele e o valor que o multímetro mostra. Nas tabelas abaixo, toque num valor para trazê-lo para cá.

Tabela deste sensor

Meça com o aparelho desligado da tomada e o sensor solto da placa. A resistência cai quando o sensor esquenta. Para saber a temperatura dele, deixe-o num copo d’água com um termômetro. Se o multímetro mostrar OL ou 1, o sensor está aberto. Valores como 0 Ω ou “curto” são termostatos e protetores, não sensores.
